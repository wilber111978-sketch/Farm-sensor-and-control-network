# Project photos

Place photographs in the matching component folder:

- `gateway/`
- `soil-nodes/`
- `tank-nodes/`
- `weather-node/`

Use descriptive filenames such as `soil-node-2-installed-front.jpg`. JPEG, PNG,
and WebP are suitable for GitHub.

Before uploading, remove GPS/location metadata and check that photos do not
show passwords, API keys, network labels, serial numbers, or private addresses.
