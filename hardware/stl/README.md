# Printable parts and 3D models

Place models in the matching component folder:

- `gateway/`
- `soil-nodes/`
- `tank-nodes/`
- `weather-node/`
- `shared/` for parts used by more than one node type

STL files are ready-to-print exports. If available, also include editable STEP
or 3MF source files next to the STL.

Use filenames such as `soil-node-enclosure-base-r1.stl`. Increase the revision
suffix when dimensions or mounting details change instead of overwriting an
older field-proven model.
